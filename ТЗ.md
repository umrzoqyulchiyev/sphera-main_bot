# Техническое задание — INTRA GROUP Radio Platform

> **Формат**: Telegram Mini App (Webapp) внутри Telegram-бота
> **Суть проекта**: Новый вид интерактивного радио, где тысячи участников отправляют мнения, а ИИ превращает их в готовый эфирный диалог. Аналогов нет.

---

## 1. Общая концепция

Платформа состоит из двух слоёв:

| Слой | Что это | Статус |
|------|---------|--------|
| **Площадка (инфраструктура)** | Аудиострим, профиль, поинты, 3 уровня, чат | Делаем сейчас |
| **ИИ-модули** | Анализ мнений, генерация диалога, TTS | Подключаем после |

---

## 2. Архитектура системы

```
Telegram Bot
    └── Mini App (Web App)
            ├── Профиль / ID / Поинты
            ├── Чат (текст + аудио)
            ├── Отправка мнений (текст / голос)
            ├── Голосование за музыку
            └── Эфир (Icecast2 stream)
                    ├── Слушатель (level 1)
                    ├── Активный (level 2)
                    └── Ведущий (level 3) — микрофон → Icecast → все слушатели
```

**Важно**: мнения и голосовые сообщения хранятся через ресурсы Telegram (file_id), не на нашем сервере — для экономии.

---

## 3. Роли и уровни пользователей

### Уровень 1 — Слушатель (по умолчанию для всех новых)
- Слушает эфир
- Читает чат
- НЕ может писать в чат и отправлять мнения (до получения поинтов)

### Уровень 2 — Активный (даётся автоматически или админом)
- Всё что у уровня 1
- Пишет в чат (текст и аудио)
- Отправляет мнения и голосует за музыку
- Может переводить и запрашивать поинты

### Уровень 3 — Доверенный / Ведущий (только admin назначает)
- Всё что у уровня 2
- Получает доступ к микрофону → выходит в эфир
- Видит свой слот эфирного времени
- Может делиться ссылкой на свой предстоящий эфир
- Платит за слот (3–5$ / час, реализуется через поинты)

### Admin
- Назначает уровни пользователям
- Создаёт темы для обсуждений
- Создаёт расписание эфиров (слоты)
- Модерирует мнения перед выходом в эфир
- Управляет системой поинтов (начисление, акции)

## 4. Профиль пользователя

Каждый участник при входе через бота получает:

| Поле | Описание |
|------|----------|
| `ID` | Уникальный числовой идентификатор |
| `Username` / `Display name` | Отображаемое имя (редактируемое) |

| `Язык` | RU / EN / LT |
| `Психотип` | (будущий ИИ-модуль) |

## 5. Система поинтов

### Расходы (за действия)

| Действие | Стоимость |
|----------|-----------|
| Отправить текстовое сообщение в чат | 0.001 поинт |
| Отправить голосовое сообщение в чат | 0.005 поинт |
| Отправить текстовое мнение в студию | 0.001 поинт |
| Отправить голосовое мнение в студию | 0.005 поинт |
| Номинировать музыку | 0.001 поинт |
| Проголосовать за музыку | 0.001 поинт |

> Голос дороже текста, потому что STT (расшифровка речи в текст) дороже в обработке. Это также создаёт возможность для акций — "сегодня голос по цене текста".

### Пополнение поинтов

| Способ | Описание |
|--------|----------|
| **Покупка пакета** | Через Telegram Stars (XTR) или карту |
| **Перевод от пользователя** | По ID: "отправить X поинтов пользователю 1234" |
| **Запрос у пользователя** | По ID: "попросить X поинтов у пользователя 1234" |
| **Подарок от admin** | Начисление без оплаты (бонусы, акции) |

### Пакеты (примерные)

| Пакет | Поинты | Цена |
|-------|--------|------|
| Старт | 100 | 1€ |
| Базовый | 500 | 4€ |
| Продвинутый | 1500 | 10€ |
| Профи | 5000 | 25€ |

## 6. Чат

- **Формат**: реальное время (WebSocket)
- **Что можно**: текстовые и голосовые сообщения
- **Что нельзя**: видеосообщения, файлы
- **Голосовые**: записываются в браузере → конвертируются в MP3 → хранятся на сервере (или через Telegram file_id)
- **История**: последние 50 сообщений

---

## 7. Отправка мнений (студия)

Участник может отправить мнение по активной теме:

1. **Текстом** — вводит вручную, стоит 0.001 поинт
2. **Голосом** — записывает аудио, стоит 0.005 поинт (STT расшифровка на сервере)

Мнения хранятся в БД и передаются ИИ-модулю для анализа (на следующем этапе).

### ИИ-обработка мнений (3 этапа — будущий модуль)

```
Этап 1: Кластеризация
  → 55% одинаковое мнение "за X"
  → 35% схожее, но другое "за Y"
  → 10% иное

Этап 2: Выявление причин
  → Почему 55% думают так?
  → Почему 35% думают иначе?

Этап 3: Генерация диалога
  → 8–10 минут разговора двух ИИ-персонажей
  → Персонажи озвучены через TTS (ElevenLabs / Edge TTS)
  → Диалог отдаётся модератору на проверку
  → После одобрения — выходит в эфир через Icecast
```

## 8. Голосование за музыку

- Admin создаёт тему для голосования
- Участники номинируют треки (исполнитель + название) — 0.001 поинт
- Участники голосуют за чужие номинации — 0.001 поинт, 1 голос на тему
- Большинство определяет, какая музыка играет в эфире
- **Важно**: музыка делится внутри Telegram-группы (не радиовещание), что юридически не требует лицензии

---

## 9. Аудиоэфир (Icecast2)

### Технология
- **Icecast2** — сервер для аудиопотоков
- **FFmpeg** — конвертация и передача аудио
- 3 потока: `/live_ru`, `/live_lt`, `/live_en`
- Слушатели подключаются через Mini App (аудиоплеер в браузере)

### Кто может вещать

| Кто | Что делает |
|-----|-----------|
| ИИ-хост (автомат) | Генерирует и читает готовый диалог из мнений |
| Ведущий (level 3) | Выходит в эфир с микрофона по расписанию (слоту) |

### Слоты эфира
- Admin создаёт временной слот: "Ведущий Иван — 20:00–21:00"
- Ведущий получает ссылку, делится в соцсетях
- Слушатели видят обратный отсчёт до начала эфира
- Ведущий платит поинтами за слот (или деньгами напрямую)

### Подключение к микрофону
- Только по разрешению модератора (admin выдаёт level 3)
- WebSocket → браузерный микрофон → FFmpeg → Icecast

---

## 10. Telegram-группа (параллельный канал)

- Обычная Telegram-группа с возможностью **группового голосового звонка**
- Модератор управляет микрофоном: сам решает кому дать/забрать слово
- Музыка делится именно здесь (не через Icecast) — избегаем лицензионных требований
- Параллельно Mini App показывает красивый интерфейс поверх Telegram

## 11. Технический стек

| Компонент | Технология | Зачем |
|-----------|-----------|-------|
| **Backend API** | Python + FastAPI | Быстрый, async, WebSocket из коробки |
| **База данных** | PostgreSQL | Надёжная, масштабируемая |
| **Кэш / Realtime** | Redis | Pub/Sub для чата и WebSocket |
| **Стриминг** | Icecast2 + FFmpeg | Аудиотрансляции тысячам слушателей |
| **Frontend** | React 19 + TypeScript + Vite | SPA внутри Telegram WebApp |
| **Стили** | TailwindCSS | Быстрая вёрстка |
| **Telegram Bot** | python-telegram-bot v22 | Авторизация, команды, payments |
| **ИИ (будущее)** | Google Gemini | Анализ мнений + генерация диалога |
| **TTS (будущее)** | ElevenLabs / Edge TTS | Озвучка диалога |
| **STT (будущее)** | faster-whisper | Голос → текст для мнений |
| **Хостинг** | Google Cloud GCP / VPS | Стабильный сервер 24/7 |
| **Туннель (dev)** | Cloudflare Tunnel | HTTPS для разработки |

## 14. Ключевые ограничения

| Ограничение | Почему |
|-------------|--------|
| Только текст и аудио в чате (без видео) | Решение клиента |
| Подключение к эфиру — только через разрешение модератора | Level 3 выдаёт только admin |
| Мнения хранятся через Telegram file_id (не на нашем сервере) | Экономия ресурсов сервера |
| Музыка — только внутри Telegram-группы | Нет лицензии на радиовещание |
| ИИ в конце, не в начале | Сначала нужна стабильная площадка |
